Software projects

Canvas to Notion Copies coursework from Canvas into a Notion table.

A Chrome extension reads assignments from a signed-in Canvas tab and sends them through a local Python server. The sync checks the Notion table before writing, skips duplicates, and preserves changes to fields like status on existing assignments. Canvas session cookies stay in Chrome.

Playtime Tracker Tracks time spent on a Minecraft server.

This Java plugin stores accumulated playtime in YAML using each player’s UUID. The /playtime command adds the current session to the saved total, so players can see their time before they log off.

Robotics and autonomy Autonomous driving for competition robots.

I work on C++ software for the Long Knights’ VEX U robots. My focus is the autonomous period, when the robot runs a sequence of actions without driver input. Developing those routines means testing how consistently the robot can repeat a move on the field.

Robot Log Replay A viewer for recorded robot telemetry.

This fictional tool reads position, heading, and motor output from a CSV file. A scrubber lets the operator compare what the robot did with what the autonomous routine expected at that point in time.

Fixture Check A command-line validator for test data.

This fictional utility validates JSON fixtures before a test run. It reports missing fields and type mismatches alongside the file and field that caused them.
