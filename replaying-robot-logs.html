Replaying a robot run from a log

A sample engineering note using fictional telemetry.

Record inputs alongside motion

A position trace tells you where the robot ended up. Recording the target heading and motor commands on the same clock lets you see whether the controller asked for the wrong turn or the robot failed to follow the right command.

Turn a short segment into a test fixture

Keep the window around the first wrong command and enough earlier samples to establish the controller’s state. Replay the inputs in timestamp order, then check the behavior that failed. For a turn, that might mean verifying that the steering command changes sign after the heading passes the target.
