This is my submission for the Midterm project for CSCI3210 (Web Application Development). I used Vite instead of Create React App because according to my research, Create React App is depricated and not recommended for use.

The project can be found on my GitHub [here.](https://github.com/nathanielgreisen/nathanielgreisen.github.io/tree/main/CSCI3210/MIDTERM)

The project can also be viewed directly on my website [here.](https://nathanielgreisen.github.io/CSCI3210/MIDTERM/)

This is the list of 15 features that I added:
1. Users can create their own accounts
2. Users can reload the canvas at any time to ensure what they are seeing is fully up to date
3. Users can select up to 16 colors to draw on the canvas
4. Users have camera controls to adjust the frame around the canvas
5. Users can type the direct coordinates of where they want to place a pixel
6. Users can see the last 50 placements, and what user added them.
7. Users can refresh the user placement history
8. Users can sign in and sign out of their accounts
9. Visitors can view the shared canvas without creating an account
10. There is a grid on the canvas, where users can see the lines between each pixel
11. The system uses Render, which allows the backend to be hosted in the cloud and thus users can use the website on GitHub pages
12. Users see a countdown showing when they can place their next pixel
13. There is a leaderboard for users to see who has placed the most pixels
14. The app automatically reconnects and catches up on missed updates after a connection drops
15. Canvas moderators can rename the shared canvas
